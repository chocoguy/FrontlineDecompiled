- MSL (`MSL_C.PPCEABI.bare.H`) and OdemuExi2 were built with deferred inlining like TRK: the
  libs now use `-inline auto,deferred`, and sources keep the original (reverse address) order.
  Over-inlining is fixed on the callee side with `#pragma auto_inline off`/`reset`
  (fflush, freopen, unicode_to_UTF8, alloc's Block_link/FixBlock_construct/SubBlock_merge_next,
  ansi_fp's __str2dec/__ull2dec/__count_trailing_zerol/__num2dec_internal). The reverse case
  (a helper the original inlined but ours called) is fixed with `#pragma always_inline on`
  (alloc's link_new_block, deallocate_from_var_pools, __pool_free, get_malloc_pool).
  `__pool_alloc` would not inline even then, so its body is written into malloc.
- MSL internal stdio header: `src/MSL_C.PPCEABI.bare.H/ansi_files.h` (FILE is 0x50 with
  `idle_proc` at 0x48; this MSL uses `_IONBF 0, _IOLBF 1, _IOFBF 2`).
- fdlibm (`fdlibm.h`): MSL changes vs stock fdlibm are acos/asin returning `NAN` for |x| > 1,
  pow setting `errno = EDOM` and returning `NAN` for a negative base with a non-integer
  exponent, ldexp checking `isfinite`, and an inline frsqrte-based sqrt.
- Runtime: runtime.c is hand asm (with `entry` for _savefpr_N etc., declared first in C);
  __mem.c is in `.init`; Gecko_ExceptionPPC.cp needs `-Cpp_exceptions on -RTTI on` and uses
  `#pragma exception_magic` / `__exception_magic` in __unexpected. Its exception-action records:
  catch-block `cinfo_ref` is signed, DESTROYMEMBERCOND's condition is a short.
- Accepted noise: datacmp does not count `.rel` words (`__files` reported 0x134 vs 0x140);
  ansi_fp's string pool lacks the DBL_MAX digit string of the stripped `__dec2num`; Gecko's
  strings are pooled in ours; OdemuExi2 register base/offset splits.
